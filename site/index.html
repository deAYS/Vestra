04 / MAKE YOURSELF AT HOME

Four steps.
Then it’s yours.

Find a Windows release ↓
  1. 01

    Get the Manager

    Choose the Windows Setup or Portable build from GitHub Releases. The alpha builds are unsigned.

  2. 02

    Choose your Discord

    Stable is selected by default. Click Install Vestra. The Manager creates a backup first.

  3. 03

    Give Discord a fresh start

    Quit Discord fully from the system tray, then open it normally.

  4. 04

    Find your Vestra

    Click the floating button or press Ctrl + Shift + V. Pick a theme and enable your plugins.

my-plugin.ts@vestra/api 
import { definePlugin, Styles }
  from "@vestra/api";

export default definePlugin({
  name: "MyAtmosphere",
  description: "A little more me.",
  authors: ["You"],
  start() {
    Styles.inject("MyAtmosphere",
      "a { text-underline-offset: 3px; }");
  },
  stop() { Styles.remove("MyAtmosphere"); }
});

A few good questions.

Does this work in the real Discord app?

Vestra modifies the Windows Discord desktop installation you select. Stable is the default; PTB and Canary discovery are also supported. The browser preview is a separate design playground.

Can I use BetterDiscord or Vencord plugins?

Vestra has its own API. Plugins from other clients need adapters and do not run unchanged. CSS themes can be imported, but their compatibility depends on the theme and current Discord version.

What if Discord updates?

Open Vestra Manager and check the installation. Use Repair if a Discord update replaced the modified files. Uninstall restores the original backup.

Is this ready for everyone?

Vestra is an early alpha. The runtime, themes, built-in utilities and Windows packaging have automated checks. A public signed plugin marketplace, signed Windows builds and npm publication are still ahead.
